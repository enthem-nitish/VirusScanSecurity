Frequently Asked Questions

Are uploaded APK files stored permanently?

No. Uploaded APK binaries are securely deleted immediately following extraction and scoring.

Does static analysis execute the APK?

Never. Static analysis strictly decompiles bytecode and inspects declarative resources without executing any binary instructions.
